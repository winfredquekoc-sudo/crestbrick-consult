Frequently asked questions

Is the ABSD embed calculator really free?

Yes. Copy the iframe snippet, paste it into your site or forum post, and it works. No sign up, no API key, no cost. The only condition is that the attribution link at the bottom of the widget stays visible.

Can I customise the size or remove the attribution link?

You can resize the iframe width and height to fit your layout. The attribution link, Built by Winfred Quek, must stay in place. That link is the only cost of using the widget for free.

Will the calculator stay updated if IRAS changes ABSD rates?
