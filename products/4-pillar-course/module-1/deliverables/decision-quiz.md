## Multiple choice

- **B.** A structural compensation model that rewards closing the next transaction, not the long-term outcome of the buyer's portfolio.

## Answer key (for self-paced graders / cohort facilitators)

| Q | Correct | Why |
|---|---|---|
| Q1 | **B** | Lesson 1.1 explicitly frames agent-mind as structural — the 60-day commission cycle — not personal or moral. A is a strawman; C and D are symptoms, not the root cause. |
| Q2 | **B** | The K & M case fails on Structure (joint-name first private blocks M's "first private" status, triggering ABSD on the second). Pillars 1, 3, 4 were not the failure points in this case. |
| Q3 | **C** | Lesson 1.2's whole frame: 1–3 events / 20 years / each move enables the next. A is exactly the agent-mind error. B is single-deal optimisation. D is too narrow. |
| Q4 | **C** | Lesson 1.3 is explicit: averaging hides risk. Any single Pillar at ≤ 3 collapses the rest over time. Even-weighting and three-of-four rules both fail to capture the cascading failure mode. |
| Q5 | **D** | Buyer pool + exit triggers = Pillar 4. A is Pillar 1, B is Pillar 2, C is Pillar 3. Knowing which Pillar a question lives in is the core literacy gate before Module 2. |

### Q6 — substantive answer markers

A passing answer should:

- Identify **at least one Pillar 2 question** (structure / next-move impact) — because the agent's pitch explicitly didn't cover it, and joint-name on first private is the highest-cost avoidable error in this profile (mid-30s couple with stated upgrade trajectory).
- Identify **at least one Pillar 4 question** (buyer pool at year 8, exit triggers) — because new launch + OCR + 3-bedder has a defined buyer pool and the agent's pitch covered marketing assumptions but not exit math.
- Justify why these two beat a Pillar 1 or Pillar 3 question *here* — namely, the agent already covered yield (Pillar 3 surface) and the bank check covers the surface of Pillar 1; the unaudited gap is Structure and Exit.

A weaker but acceptable answer might pick Pillar 1 (stress test) and Pillar 4 (exit). Mark down for any answer that picks two questions inside the same Pillar, or that doesn't name which Pillar each addresses.
