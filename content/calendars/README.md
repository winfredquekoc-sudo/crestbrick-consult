# Content Calendars

Quarterly planning artifacts. Each quarter follows the 4-Pillar rotation across 13 weeks.

## Cadence

- **Q1 (Jan-Mar):** Affordability arc opens the year; URA Q1 release + HDB Q1 BTO + CNY + IWD anchor markers.
- **Q2 (Apr-Jun):** Stamp Duty + Structure arc opens; URA Q2 release + HDB Q2 BTO + Father's Day markers.
- **Q3 (Jul-Sep):** Cash Flow arc opens; URA Q3 release + National Day + HDB Q3 BTO markers.
- **Q4 (Oct-Dec):** Exit Strategy arc opens; URA Q4 release + budget preview + year-end audit push markers.

## Files

- `q1-2026.md` — Jan 5 to Apr 5, 2026 (13 weeks, ~80 pieces)
- `q2-2026.md` — TBD

## Standards

- Every public piece ends with exactly one CTA drawn from `~/.claude/state/cta-library.json`
- Each anchor piece ties to one lead magnet from `~/.claude/state/lead-magnets.json`
- Each newsletter is routed to a segment defined in `~/.claude/state/email-segmentation.json`
- Pillar rotation: P1 Affordability → P2 Stamp Duty + Structure → P3 Cash Flow → P4 Exit Strategy. No back-to-back repeats.
- Recurring weekly slots: Mon market scout digest, Wed tool spotlight, Fri case study.
- Special calendar markers (CNY, IWD, National Day, URA quarterly, HDB BTO) override the default cadence for that week's softer slots only — anchor pillar holds.

## Generation

Quarterly plans are generated by the content-calendar-agent worker via Claude Agent SDK. Re-run at the start of each quarter or when a major regulatory event (cooling measures, ABSD revision) invalidates the existing plan.
