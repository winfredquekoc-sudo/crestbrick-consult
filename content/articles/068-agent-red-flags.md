# Agent Red Flags: Don't Hire These

**Red flag 1:** "I'll definitely get $750k" (overpricing)
Market says $700k. Agent promises $750k to win listing. Reality: Listing overpriced, doesn't sell.

**Red flag 2:** No market analysis provided
You ask "Why this price?" Agent says "Feels right." No comps, no data = bad agent.

**Red flag 3:** Poor communication
Doesn't return calls in 24 hours = red flag.
Doesn't update you on showings = red flag.

**Red flag 4:** Low market knowledge
Can't explain current conditions, doesn't know local comps, unfamiliar with buyer profiles = red flag.

**Red flag 5:** High commission without justification
Wants 2.5% without explaining value = red flag.

---

## What Good Looks Like

- Realistic pricing (backed by data)
- Regular updates (showings, feedback, comps)
- Market knowledge (can explain cycles, trends)
- Responsive (calls back within 2 hours)
- Reasonable commission (2-2.25%)
