# Tenant-Landlord Matching Checklist

## Overview
This checklist ensures every tenant is matched against every available landlord using consistent, bias-free criteria. The three-tier system prioritizes hard requirements, flags soft negotiation points, and identifies fast-track matches.

---

## Tier 2: Soft Flags Checklist
**⚠️ These are negotiable. Proceed but note for discussion.**

### For Landlord: Mrs. Chong

- [ ] Tenant budget: SGD `___` /month
- [ ] Room offered:
  - Master: $2,300 (Mrs. Chong's ask)
  - Common: $1,300 (Mrs. Chong's ask)
- [ ] Tenant budget vs. asking:
  - 20%+ above ask? → ✅ GREEN-LIGHT (fast-track)
  - Within ±10% of ask? → ✅ YELLOW (acceptable, no negotiation)
  - 10–20% below ask? → ⚠️ AMBER (flag for negotiation discussion)
  - 20%+ below ask? → 🚩 RED (discuss, but may work)
- [ ] Action: `________________` (note negotiation strategy)

#### Cooking & Food Habits
- [ ] Tenant cooks at home?
  - Frequently → Mrs. Chong: "no problem" = ✅
  - Occasionally → ✅
  - Never → ✅
- [ ] Any dietary restrictions requiring special kitchen? 
  - YES → Discuss with Mrs. Chong ⚠️
  - NO → Continue ✅

#### Visitor & Guest Policy
- [ ] Tenant expects overnight guests?
  - Never → ✅ (Mrs. Chong: "no overnight guests" = match)
  - Occasionally → ⚠️ SOFT FLAG (discuss with Mrs. Chong; she might be flexible)
  - Frequently → 🚩 HARD MISMATCH (likely conflict)
- [ ] Day visitor frequency?
  - Any → ✅ (Mrs. Chong allows day visitors)

#### Occupation & Lifestyle Fit
- [ ] Tenant occupation: `___` 
- [ ] Mrs. Chong soft preference: Students & young professionals
- [ ] Occupation match:
  - Student? → ✅ GREEN (Mrs. Chong approves)
  - Professional? → ✅ GREEN (likely match)
  - Other? → ⚠️ YELLOW (acceptable, no issues noted)
- [ ] Work hours / noise profile likely compatible?
  - YES → ✅
  - UNSURE → ⚠️ Flag for interview

#### Lease Duration Fit
- [ ] Tenant wants: `___` months
- [ ] Mrs. Chong prefers: 24 months (2 years)
- [ ] Match:
  - 24+ months? → ✅ PERFECT (exceeds preference)
  - 12 months? → ✅ ACCEPTABLE (meets minimum)
  - <12 months? → ❌ HARD REJECT (below minimum)

#### Utilities & Power Consumption
- [ ] Tenant household profile: `___` (e.g., single, couple, family)
- [ ] Expected power usage: Low / Medium / High?
- [ ] Mrs. Chong concern: Excessive usage (mining, industrial equipment)
- [ ] Risk assessment:
  - **Low** (single student, normal usage) → ✅
  - **Medium** (couple, moderate appliances) → ✅
  - **High** (group with gaming/mining equipment) → 🚩 HARD REJECT

  - YES → ⭐ PLUS POINT (stable income, low risk)

  - YES → ⭐ PLUS POINT (less kitchen usage, utilities lower)
  
- [ ] Tenant references/profile indicates **excellent history** (previous tenants happy)?
  - YES → ⭐⭐ PRIORITY (low risk, high trust)

### Green-Light Scoring
**Sum the stars. 5+ stars = Fast-track.**

| Score | Action |
|-------|--------|
| 0–1 ⭐ | Meets minimum criteria; proceed normally |
| 2–3 ⭐⭐ | Good match; mark as priority |
| 4–5 ⭐⭐⭐ | Excellent match; fast-track to landlord |
