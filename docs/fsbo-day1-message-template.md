## How to Execute (2 Minutes)

### Step 1: Find FSBO Listing
- Carousell → Property → "For Sale By Owner"
- Note block name, unit (if shown), asking price

### Step 2: Pull PropertyGuru Data
1. Go to PropertyGuru.com.sg
2. Search the block name
3. Filter: HDB + Sold
4. Screenshot/note last 3 sold units:
   - Unit number
   - Sale price
   - Date sold

### Step 3: Fill in the Template
Replace:
- `[Name]` → Their name (if visible)
- `[Block]` → Their block name (e.g., "Bishan Block 123")
- `[X]k` → Their asking price (e.g., "615k")
- The 3 PropertyGuru sales → REAL recent sales from PropertyGuru

### Step 4: Send
Copy message + send via WhatsApp (if you have their number) or Carousell DM/comment.
